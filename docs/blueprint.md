# **App Name**: Solana Vault Manager

## Core Features:

- Wallet Connection: Connect to a Solana wallet using a browser extension.
- Balance Display: Display the total ASMV balance in the connected wallet.
- NFT Listing: List all NFTs owned by the connected wallet.
- NFT Details: Show the vault balance for each NFT.
- Deposit ASMV: Allow users to deposit ASMV into a selected NFT vault by entering the NFT mint address and the amount to deposit.
- Redeem ASMV: Allow users to redeem ASMV from a selected NFT vault by entering the NFT mint address and the amount to redeem.
- Mint NFT: Allow users to mint new NFTs.

## Style Guidelines:

- Primary color: Dark blue (#243A73) to evoke a sense of trust and security, as befits a financial application.
- Background color: Very light blue (#E0E5F1), almost white but visibly of the same hue as the primary color.
- Accent color: Purple (#6849D4), to create visual interest while remaining analogous to the primary blue.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines, and 'Inter' (sans-serif) for body text.
- Position the wallet selection and connection section in the upper right corner for easy access.
- Display NFTs in a horizontal scrolling list with card-style presentations, each showing vault balance and deposit/redeem actions.
- Use consistent and professional icons for wallet connection, deposit, redeem, and minting actions.
